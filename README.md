# 知己 · 健康手记（网页 App）

移动优先 H5，免登录，数据存本机 `localStorage['zhiji_v3']`。

## 本地预览

用任意静态服务器打开本目录（勿用 `file://`，音频/部分浏览器能力会受限）：

```bash
npx --yes serve .
```

浏览器访问提示的地址；手机调试可用同一局域网 IP。

## 你需要准备的素材（可选）

将 mp3 放到 `assets/audio/`，文件名与下表一致后即可替换内置「程序生成」占位音：

| 文件 | 用途 |
|------|------|
| `rain.mp3` | 雨声 |
| `piano.mp3` | 轻柔钢琴 |
| `body-scan.mp3` | 身体扫描 |
| `breath.mp3` | 腹式呼吸 |

未放置文件时，点播放会用浏览器生成轻柔白噪声/柔和音作为临时体验。
